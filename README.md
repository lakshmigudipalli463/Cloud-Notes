# ☁️ Cloud Notes

Cloud Notes is a simple web-based notes application developed and deployed using Firebase Hosting.

## 🚀 Live Demo

https://theta-totem-510416-m1.web.app

## ✨ Features

- Add notes
- Delete notes
- Simple and responsive interface
- Deployed using Firebase Hosting

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Hosting
- Google Cloud Platform

## ☁️ Cloud Deployment

The application is hosted on Firebase Hosting and connected to a Google Cloud project.
